수업 열기

처음 쓰는 수업 코드면 새 수업이 만들어지고, 쓰던 코드면 로그인돼요. 같은 코드와 비밀번호로 매 수업 다시 들어오면 됩니다.

학생 접속 안내
  1. 주소 접속
  2. 이름 쓰고, 수업 코드 입력
  3. 자기 모둠 번호 누르기

수업 설정

그림을 보고 맞힐 때: 자유 입력은 직접 쓰기(단어가 잘 바뀌어 재미있음, 고학년), 글자 카드는 정답 글자가 섞인 카드를 눌러 완성(저·중학년), 객관식은 보기 4개 중 고르기(1~2학년, 단어 학습). 힌트는 누를 때마다 한 단계씩: 글자수(카드는 첫 글자) → 초성 → 설명.

🤖 AI로 설명 힌트 채우기 (Google AI Studio, 무료)

① aistudio.google.com/apikey에서 구글 계정으로 API 키를 만들어 아래에 붙여 넣으세요. ② 버튼을 누르면 설명이 없는 단어에만 초등학생용 설명을 만들어 목록에 채워요. 꼭 읽어 보고 고쳐 주세요. 키는 이 브라우저에만 저장되고 서버에는 올라가지 않아요. AI에는 제시어 목록만 보내고 학생 정보는 보내지 않아요.

각 학생은 첫 순서에 이 목록에서 무작위로 나온 3개 중 하나를 골라 시작해요. 한 단어는 20자까지.

바꾸면 자동으로 저장돼요

이 화면을 열어 둔 동안 학생들이 그리는 중인 그림이 3초마다 보여요. 장난친 그림·답은 🙈 가리기로 지우면 다음 사람과 결과 발표에 나오지 않아요. 🚫 강퇴한 학생은 모둠 방을 새로 열 때까지 이 모둠에 다시 못 들어오고, 남은 차례는 건너뛰어요.
